# Lawn Republic Marketing Site

High-converting marketing website for Lawn Republic (Tulsa-area weed control & fertilization).

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## Getting Started
```bash
npm install
npm run dev
```

## Deployment
Deploy-ready for Vercel (Node 20).

## Environment Variables
Create a `.env.local` if you want to enable analytics:
```
NEXT_PUBLIC_GA_ID=
NEXT_PUBLIC_GOOGLE_ADS_ID=
```
